# FMP Project

This is my Final Major Project developed in Unity using C#.

The project was created to develop my skills in game design, programming, and problem-solving while producing a complete playable game. During development I worked on gameplay systems, UI design, level creation, and visual effects. So overall i made a 2d dungeon crawler in unity.

# How it plays

You start in the tutorial area with no weapon. Walk up to the guns, press E, and they get enabled on the player. From there:

Find the key. It spawns in one of two random spots each run, so you can't just memorise it.
Press E to grab it and every door tagged Door unlocks.
Walk into the boss room and the doors lock behind you, the boss health bar appears, and three waves of zombies spawn as you chip the boss down.
Clear it and you hit the end screen with your final score.

Enemies only chase you once they're aware of you (there's a separate awareness script that checks range before the movement script does anything), so you can pick your fights if you're careful.
